# Kyeong Hun Yang — Portfolio

Personal portfolio for Kyeong Hun Yang, a computer science student, CompTIA Security+ certified technologist, and U.S. Air Force veteran. The site highlights software, security, and AI evaluation projects alongside work experience, education, and a downloadable résumé.

**Live site:** https://kyeong6250.github.io/

## What is on the site

- Featured work in Python, Java, JavaScript, and secure application development
- Experience in Air Force medical logistics, AI evaluation, and cybersecurity training
- Education, certifications, and contact links
- Responsive dark theme with subtle motion, active navigation, and reduced-motion support

## Run locally

No build step or dependencies are required. From this directory, run:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173/`. You can also open `index.html` directly, though a local server better matches GitHub Pages.

## Update content

- `index.html` contains page content and base layout.
- `enhancements.css` contains the visual theme, animations, and responsive styles.
- `script.js` handles the mobile menu, scroll reveals, active navigation, and card effects.
- `assets/Kyeong-Hun-Yang-Resume.pdf` is the public résumé download. Replace this file when publishing a new résumé; keep score reports and other private documents out of the repository.

GitHub Pages publishes updates from the repository's `main` branch.
